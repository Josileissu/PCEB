# CYPE (CYPE 3D, CYPECAD)

| Fabricante | Licença | Plataforma | Instalado aqui |
|---|---|---|---|
| CYPE Ingenieros (Espanha) | comercial, por módulos | Windows | ✓ CYPE 3D 2026.c (`C:\CYPE Ingenieros\Versão 2026`) — só CYPE 3D |

## Modelagem
- CYPE 3D: estruturas de barras 3D (aço, madeira, alumínio, concreto), ligações.
- CYPECAD (não instalado): edifícios de concreto armado.

## Análise
- Linear e 2ª ordem (P-Δ), dinâmica/sísmica, flambagem; placas e cascas limitadas no CYPE 3D.

## Dimensionamento
- Diversas normas, incluindo brasileiras (NBR 8800 aço, NBR 6118 concreto no CYPECAD); fundações isoladas.
- Ligações metálicas (CYPE Connect / ligações do CYPE 3D).

## Detalhamento
- Armaduras de fundações e peças de concreto (CYPECAD); no CYPE 3D, desenhos de ligações e chapas.

## Fabricação / CAM
- Exporta para fabricação metálica (DSTV/NC a confirmar) e Tekla via IFC.

## Documentação
- Pranchas DWG/DXF/PDF, memoriais.

## Importa / exporta
- IFC, **Open BIM / BIMserver.center** (projeto colaborativo na nuvem), DXF/DWG, Revit (plugin Open BIM).

## API / automação
- Não há API pública conhecida; integração pelo ecossistema Open BIM (arquivos IFC/JSON).

## Pré-moldados
- Limitado (lajes pré-fabricadas no CYPECAD); não é um programa de pré-moldados.

## O que aproveitar
- Modelo **Open BIM**: vários programas pequenos que trocam dados por um servidor/IFC — ideia útil para web + desktop.
