# Tekla Structures (+ Tekla Structural Designer)

| Fabricante | Licença | Plataforma | Instalado aqui |
|---|---|---|---|
| Trimble | comercial (assinatura) | Windows | não |

## Modelagem
- Modelo LOD alto para aço e concreto (moldado e **pré-moldado**): peças, cast units, insertos, componentes
  paramétricos (consolos, dentes, cálices, ligações), numeração automática de peças iguais.

## Análise
- Tekla Structures: modelo analítico com ligação a SAP2000, Robot, STAAD etc.
- Tekla Structural Designer (separado): análise e dimensionamento de edifícios (EC, ACI, BS…).

## Dimensionamento
- No Structures, não; no Structural Designer, sim (sem NBR conhecida).

## Detalhamento
- Armaduras 3D (rebar sets, malhas, protensão), **desenhos automáticos** (GA, peça, cast unit, armadura)
  com padrões configuráveis e atualização ao alterar o modelo.

## Fabricação / CAM — **ponto mais forte**
- Pré-moldado: **Unitechnik**, **PXML**, **BVBS** (dobra de barras), ELiPLAN, HMS; aço: DSTV/NC, DXF de chapas.
- Listas de produção, pesos, volumes, organizer de lotes/transporte.

## Documentação
- Desenhos DWG/DXF/PDF, relatórios configuráveis (templates), Tekla Model Sharing.

## Importa / exporta
- IFC (forte), DWG/DXF, SketchUp, CIS/2, Trimble Connect.

## API / automação
- **Tekla Open API (.NET)**: modelo, desenhos, plugins de componentes; macros C#.

## Pré-moldados
- Referência mundial de **detalhamento e fabricação** de pré-moldados.

## O que aproveitar
- Conceitos: cast unit, numeração de peças iguais, componentes paramétricos, formatos CAM — vários já
  aparecem no StructuralDetailer (marcas, assemblies).
- Lista de formatos CAM para o item 4.5 dos requisitos.
