## Material de terceiros que pode servir depois
- **Teses sobre pré-moldados** (página de pré-moldadas): ligações semirrígidas (Ferreira, Miotto, Catoia), cálices (Canha,
  Campos, Ebeling, Jaguaribe), consolos com fibras (Costa, 2009), estabilidade global (Marin, Jeremias, Lins), lajes
  alveolares (Marquesi, Costa, Petrucelli, Camillo). Úteis na fase de análise (ligações semirrígidas, D8 e seção 3.1 do escopo).
- **Catálogos de fabricantes** (Cassol, Protendit, Munte, Tatu, BPM…): seções e cargas de lajes alveolares e vigas — base de
  dados para os catálogos de produtos (D28).
- **Manuais DNIT e FHWA**: só se pontes entrarem no escopo.
