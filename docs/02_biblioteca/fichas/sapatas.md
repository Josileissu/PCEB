# Sapatas — Bastos

- **Fonte**: BASTOS, P.S.S. *Sapatas de Fundação*, UNESP Bauru, 2023, 119 p. — `artigos/pbastos/Sapatas.pdf`
  (<https://wwwp.feb.unesp.br/pbastos/concreto3/Sapatas.pdf>). Base: NBR 6118:2023 (22.6), NBR 6122.
- **Conteúdo**: tipos, distribuição de tensões no solo, sapata isolada rígida e flexível (biela, CEB-70), sapata corrida,
  estabilidade, escorregamento da armadura, sapata de divisa com viga de equilíbrio, excêntrica, associada; exemplos.
- **Uso no PCEB**: fase 3 (fundações). Disposições de detalhamento (22.6.4.1: armadura de flexão uniformemente distribuída,
  ancoragem com gancho, armadura de arranque do pilar) para o futuro template de sapata — o Plugin Struct já arma sapatas no
  Revit, é a referência de mercado para comparar.
