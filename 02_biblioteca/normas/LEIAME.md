# Normas

**As normas não são distribuídas com o PCEB** (direitos autorais). Esta pasta existe no repositório vazia, só com:
- este LEIAME;
- `NORMAS_REFERENCIA.txt` — lista de **subpasta/nome de arquivo** que o programa usa para encontrar cada norma.

Quem usar o PCEB obtém as próprias cópias e as coloca aqui com os nomes da lista. O conteúdo da pasta é ignorado
pelo Git (`.gitignore`).

Mantenedor: a biblioteca de origem é `S:\Meu Drive\Normas`, indexada para busca em
`armadura/info_auxiliar/indice_normas`. Ao incluir normas novas, regenere `NORMAS_REFERENCIA.txt`.
