Documentação técnica.

O necessário para compilar, instalar e operar o DEB no CAD e no Revit. Os documentos completos ficam no repositório, versionados junto com o código.

Comece por aqui Requisitos: Windows x64, .NET SDK 8 (e .NET 10 para AutoCAD 2027).
Para o Revit: Revit 2025 ou 2026 instalado.

Instalação

No CAD, em três passos.

O instalador único detecta GstarCAD, AutoCAD e ZWCAD. Também é possível instalar manualmente.

Compile

Com o .NET SDK instalado, compile a solução ou o projeto do CAD desejado.

dotnet build src\DEB.GstarCAD -c Release

Para AutoCAD: src\DEB.AutoCAD. Para ZWCAD: src\DEB.ZWCAD.

Gere o instalador

Rode o script do instalador ou copie a DLL e registre o autoload manualmente.

src\DEB.Cad\instalador\gerar.bat

Requer .NET 8, .NET 10 em %LocalAppData%\Microsoft\dotnet10 e Inno Setup 6. A saída fica em src\DEB.Cad\instalador\saida.

Abra o CAD

No primeiro uso, o CAD pergunta se deve carregar o plugin. Depois, abra a paleta.

ARMPALETA · ARMCOMANDOS

O comando ARMSOBRE mostra a versão instalada.

Instalação manual

O AutoCAD usa o autoloader em %AppData%\Autodesk\ApplicationPlugins. O GstarCAD usa o registro de autoload. O passo a passo completo está em INSTALACAO.txt e INSTALACAO_AUTOCAD.txt no repositório.

Antes de atualizar

Feche o CAD. Se o plugin estiver carregado, a DLL fica bloqueada e a cópia falha. O instalador novo substitui a versão anterior como atualização.

Instalação

No Revit, com a aba Detalhamento.

Compile

Feche o Revit. Compile para a versão instalada; o plugin é copiado para a pasta de Addins.

dotnet build -c Release -p:RevitVersion=2025

Use 2026 para o Revit 2026.

Abra o Revit

Na primeira carga, escolha "Sempre carregar". A aba Detalhamento aparece no Ribbon.

Botões: Detalhar peça, Pilares pré-moldados, Configurar.

Configure o padrão

Ajuste escalas, templates de vista, carimbo e margens no JSON do escritório.

%AppData%\PCEB\DEB.Revit\DetalhamentoConfig.json

Os padrões de prancha ficam em %AppData%\PCEB\DEB.Revit\Padroes.

Formatos

Dados que viajam com o projeto.

O DEB não depende de banco externo. A informação fica no arquivo e pode ser lida por outras ferramentas.

XData ARMADURA_BR

Guarda os dados de cada armadura dentro do DWG, junto com a configuração do desenho.

.cad do QiArmaduras

Importação de barras, estribos, faixas e indicações vindas do AltoQi Builder.

CSV e HTML

Lista de corte e dobra pronta para planilha e para impressão, com o desenho de cada posição.

JSON

Configuração do CAD e padrões de prancha do Revit, versionáveis por escritório.

Normas

Referência brasileira, sem atalho.

O núcleo aplica regras de detalhamento da NBR 6118 (pinos de dobramento e traspasse) e conversa com a NBR 9062 nos pré-moldados. As pranchas do Revit seguem margens da NBR 10068.

O que isso significa

As tabelas e geometrias seguem a norma, mas o plugin não substitui a verificação do engenheiro nem emite selo de conformidade.

FAQ

Dúvidas de instalação.

Para problemas específicos, abra uma issue no repositório com a versão do CAD/Revit e o log.

Abrir issues
O plugin não carrega no CAD. O que verificar?

Confirme a versão do CAD, o framework do build e o registro de autoload. Feche o CAD antes de recompilar; DLL bloqueada é a causa mais comum.

Preciso de qual .NET?

O núcleo e os testes usam .NET 8. O AutoCAD 2027 exige .NET 10. GstarCAD e ZWCAD usam .NET Framework 4.8 nas versões mais antigas.

O Revit não mostra a aba Detalhamento.

Verifique se o build foi feito para a versão correta (2025 ou 2026) e se o add-in foi copiado para a pasta de Addins. Na primeira carga, escolha "Sempre carregar".

O desenho abre em outro computador?

Sim. O DWG usa entidades nativas e abre legível. Sem o plugin, apenas as atualizações automáticas deixam de ocorrer.

Onde ficam os logs?

No CAD: %AppData%\PCEB\DEB.Cad\logs\autoteste.txt. No Revit: pasta %AppData%\PCEB\DEB.Revit.
