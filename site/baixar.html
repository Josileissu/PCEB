DEB — CAD e Revit

Como obter hoje

Do código ao CAD, em três passos.

Requer familiaridade com linha de comando. O instalador gerado é o mesmo usado para distribuir o plugin.

Clone o repositório

Baixe o código do PCEB para uma pasta local.

git clone https://github.com/Josileissu/PCEB.git
cd PCEB

Gere o instalador

O script compila GstarCAD, AutoCAD e ZWCAD em todas as versões e chama o Inno Setup.

src\DEB.Cad\instalador\gerar.bat

Requer .NET 8, .NET 10 em %LocalAppData%\Microsoft\dotnet10 e Inno Setup 6.

Instale

Rode o executável gerado em src\DEB.Cad\instalador\saida. Ele detecta os CADs instalados e registra o autoload de cada um.

DEB_Setup_0.1.26.exe

Para instalação manual, use INSTALACAO.txt e INSTALACAO_AUTOCAD.txt em src\DEB.Cad.

Demonstração

Uma hora para testar.

A versão de demonstração é gerada na compilação e expira após 1 hora de uso. Serve para avaliar o fluxo completo antes de decidir pela instalação. 

dotnet build src\DEB.AutoCAD -c Release `
  -p:Demo=true

Os binários saem em bin\demo\<CAD><versão>\.

O que a demo não faz

Não calcula estruturas, não remove o aviso de responsabilidade e não substitui a licença. É o mesmo plugin, com limite de tempo.

Antes de comprar ou instalar

Valide o fluxo do seu escritório: camadas, escalas, carimbo e padrão de prancha. O DEB se adapta por configuração, mas o desenho de referência é seu.

FAQ

Sobre o download.

A distribuição pública ainda não tem canal definido. Até lá, o repositório é a fonte oficial.

Por que não há um botão de download direto?

O canal de distribuição do instalador ainda está em preparação. Para não prometer um arquivo que não existe, o site indica o caminho real: compilar do repositório.

O código é aberto?

Sim. O repositório está no GitHub e a licença é GPL-3 com exceção para APIs proprietárias.

Posso usar em mais de um computador?

A licença não impõe limite de máquinas. O instalador é o mesmo; a versão de demonstração expira em 1 hora por execução.

O instalador substitui a versão antiga?

Sim. O AppId do instalador é mantido para que a nova versão seja reconhecida como atualização.

Dúvida técnica antes de instalar?

A documentação cobre comandos, formatos e solução de problemas. O repositório recebe issues.
